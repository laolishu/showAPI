# Swagger / OpenAPI 文档转换工具：MVP 发布说明

> 版本：0.1.0  
> 发布日期：2026-08-28  
> 状态：MVP 可交付

## 1. 功能概览

| 能力 | 说明 |
|------|------|
| 输入格式 | Swagger 2.0、OpenAPI 3.0（JSON / YAML） |
| 输入方式 | 文件拖拽、文件选择、文本粘贴 |
| 文件大小 | 最大 10 MB |
| 接口规模 | 建议 300 个接口以内（已验证 300 接口 < 2s） |
| 导出格式 | Word (.docx) |
| 导出范围 | 全部接口 / 按 Tag 筛选 |
| 语言 | 中文 / 英文（自动检测浏览器语言，可手动切换） |
| 运行环境 | 纯前端，无需后端，支持离线使用 |

## 2. 已知限制

| 编号 | 限制 | 影响 | 后续计划 |
|------|------|------|----------|
| L-01 | 不支持 OpenAPI 3.1 | 3.1 规范中的 `prefixItems`、`content` 等新特性无法解析 | P3-02 |
| L-02 | 不支持外部 `$ref` | 引用 `http(s)://` 或文件路径的 `$ref` 会被拒绝并提示 | 后续版本 |
| L-03 | 循环引用最大展开 8 层 | 超过 8 层的嵌套引用会截断并显示"已截断"提示 | 可配置化 |
| L-04 | 不支持 PDF 导出 | 仅支持 Word (.docx) | P3-05 |
| L-05 | 不支持批量转换 | 一次仅处理一份 API 文档 | P3-04 |
| L-06 | 不支持逐接口勾选 | 导出范围为"全部"或"按 Tag"，不支持手动勾选单个接口 | 后续版本 |
| L-07 | 无 Logo / 主题色配置 | 使用默认模板，不支持自定义品牌 | P3-01 |
| L-08 | 外部分析脚本 | `index.html` 中引用了外部分析脚本，断网时该脚本加载失败但不影响核心功能 | 可移除 |

## 3. 用户操作指南

### 3.1 基本流程

1. **导入文档**：拖拽 `.json` / `.yaml` / `.yml` 文件到页面，或点击选择文件，或直接粘贴 JSON/YAML 文本
2. **预览接口**：解析成功后自动展示接口列表，可按 Tag 筛选
3. **查看详情**：点击接口条目展开参数、请求体、响应等详细信息
4. **导出 Word**：填写项目名称（可选）→ 选择导出范围 → 点击"导出 Word (.docx)"

### 3.2 语言切换

- 首次访问自动检测浏览器语言（中文浏览器 → 中文界面，其他 → 英文界面）
- 点击页面右上角「中文 / EN」按钮可随时切换
- 选择会记住，下次访问自动恢复

### 3.3 离线使用

- 所有解析和导出均在浏览器本地完成
- 断网后核心功能（导入、解析、预览、导出）完全正常
- 无需安装任何后端服务

## 5. 技术栈

|------|------|

npm run build

node scripts/perf-test.mjs        # 性能测试
