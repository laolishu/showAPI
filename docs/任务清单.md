- `已阻塞`：存在外部依赖或明确问题。

## P1：核心开发链路

| ID | 任务 | 状态 | 备注 |
| --- | --- | --- | --- |
| P1-01 | 初始化纯前端工程与基础页面 | 已完成 | Vue 3 + TypeScript + Vite 工程已创建；已安装 `yaml`、`@apidevtools/swagger-parser`、`docx`；基础页面含导入区、配置区、预览占位；`vue-tsc` 类型检查通过，`vite build` 构建成功。 |
| P1-02 | 实现文件上传、拖拽与文本粘贴 | 已完成 | `useApiInput` composable 已实现：文件选择/拖拽/粘贴三种输入方式、10MB 大小校验、扩展名验证、格式自动检测（JSON/YAML）、拖拽高亮状态、清除重置；`App.vue` 已接入；`vue-tsc` 类型检查通过，`vite build` 构建成功（69.35 kB JS / 3.07 kB CSS）。 |
| P1-03 | 实现 Swagger/OpenAPI 解析与版本适配 | 已完成 | `openapi-parser.ts` 实现 Swagger 2.0 / OpenAPI 3.0 版本检测、info/tags/servers/operations/schemas 提取；`schema-utils.ts` 实现 $ref 解析、allOf 合并、oneOf/anyOf 候选保留、循环引用保护（accessStack）、最大 8 层深度限制、外部 $ref 拒绝；`useApiParser` composable 自动监听输入变化并解析；`vue-tsc` 类型检查通过，`vite build` 构建成功（184.78 kB JS）。 |
| P1-04 | 实现 `$ref` 与常见 Schema 处理 | 已完成 | 包含在 P1-03 的 `schema-utils.ts` 中：内部 $ref 解析、循环引用检测（accessStack）、最大 8 层展开、allOf 字段合并、oneOf/anyOf 候选模型名保留、外部 $ref 标记拒绝。 |
| P1-05 | 实现解析结果预览与 Tag 筛选 | 已完成 | `App.vue` 已实现：解析摘要（版本/接口数/Tag 数/模型数）、Tag 筛选按钮、接口列表（方法徽章+路径+名称+废弃标记）、展开详情（参数表/请求体/响应表）、错误与警告提示；`vue-tsc` 类型检查通过，`vite build` 构建成功。 |
| P1-06 | 实现 Word 默认模板导出 | 已完成 | `word-exporter.ts` 实现：封面（项目名/版本/时间）、文档概述、接口目录表、按 Tag 分组的接口详情（基本信息+参数表+响应码表+响应字段表）、数据模型附录；使用 `docx` 库生成 .docx 并触发浏览器下载；`vue-tsc` 类型检查通过，`vite build` 构建成功。 |
